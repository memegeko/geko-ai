# Security

Report suspected vulnerabilities privately to the repository maintainer.
Do not include live cookies, OAuth secrets, recovery codes, or user databases
in a public issue.

Standalone installations require HTTPS except on loopback. Keep the app behind
a trusted reverse proxy, preserve the loopback-only Compose binding, and replace
client-controlled forwarded IP headers. Authentication includes invite checks,
password hashing, HttpOnly cookies, origin validation, database-backed rate
limits, optional TOTP, and a session-bound application gate for social-login 2FA.

Protect `.env` and SQLite files, back up both, and apply dependency updates with
regression tests. The database is not whole-file encrypted. The application
administrator controls inference endpoints; users with that role can reach
private network URLs by default. Do not grant administrator access to untrusted
accounts. Treat character definitions and model output as untrusted content.

The app has no model-side tool execution, shell execution, or browser automation
capability. Text generated by a character does not authorize server actions.
